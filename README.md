# Financial Market Analyzer

## Overview

Financial Market Analyzer is a Python project that compares the historical performance of financial assets using live market data from Yahoo Finance.

Users can select a time period, enter three assets to compare, and generate visualisations to analyse market performance.

---

## Features

- Select different time periods
- Compare three financial assets
- Automatic market data download
- Individual price charts
- Percentage change comparison
- Correlation analysis

---

## Technologies

- Python
- Pandas
- Matplotlib
- yfinance
- Google Colab

---

## Example

Compare:

- Reliance
- Bitcoin
- Gold

Output:

- Individual price charts
- Percentage change comparison
- Correlation matrix
- Performance summary
